Introduction

Here we are going to analyse and explore the 2015 BRFSS Diabetes Health Indicators data set.

Variables

Response variable: Diabetes_binary

Demographics Variables: Age, Education, Smoker, Sex, Income

Clinical Variables: BMI, PhysActivity, HighBP, HighChol, CholCheck, Stroke, HeartDiseaseOrAttack, …

For this EDA I will explore Age, Physical Activity, and BMI, as all three variables have strong well established links as risk factors for Diabetes.

Physical Activity helps regulate blood glucose, and constant sedentary behavior has been linked to increases diabetic risk.

Age leads to diabetic incidence rising as beta-cell function declines

BMI is a well established risk factor and high amount of fat lead to insulin resistance

In addition to these from the exploratory data analysis we will also be including high cholesterol and high blood pressure

High Blood Pressure Frequently occurs alongside diabetes and is considered a common comorbidity. Chronically high blood pressure can damage blood vessels and impact insulin delivery increasing diabetic risk.

High cholesterol is often found in individuals with type 2 diabetes. It can affect underlying insulin resistance and cardiovascular function making it important to consider in predictive modeling.

Log Regression Model

A logistic regression model is a classification algorithm used to model the probability of a binary outcome. Unlike linear regression which predicts a continuous value, logistic regression estimates the probability given inputs in particular categories. For this data set the response variable is diabetes _binary making logistic regression an appropriate technique.

This model works by transforming linear predictors using a sigmoid function which maps the values and as allows us to interpret the output as probability.

We will use logistic regression for this data set because the target variable is binary, the data set offers appropriate explanatory variables that relate to the probability of having diabetes, and it is a strong model to form a baseline before exploring other multiple alternatives.

Classification Tree

A classification tree is a non paramedic model used for predicting categorical outcomes. It works by splitting the data set based on values of predictor variables to create decision rules that relate to predictions. Each node of the tree represents a decision based off one of the predictors in each terminal node assigns a prediction.

We can use a classification tree for this data because they are very highly interpretable and easy to visualize. They can readily capture non-linear relationships as well as interactions between different variables, and they don’t make any assumptions about the distribution of predictors or response variables. However since trees can easily overfit it is important to tune the complexity to balance fit.

Random Forest

A random forest is an ensemble learning method that builds a collection of decision trees and combines their predictions to produce more accurate and robust models. Each tree is trained on a bootstrap sample of the data and each split is a random subset of predictors rather than all of them. This randomness helps reduce variance and makes the final model less prone to overfitting.

We will use a random forest because while classification trees very intuitive they’re also highly variable models and small changes in the data can lead to wildly different trees. Random forests addressed this limitation by averaging the predictions, and lead to better generalizations.
